# Enigma 0.13.3

Edit a sent message, regenerate any reply, drag in files and images, long chats that keep going, and a weather card the character dresses up for.

## New

- **Edit a sent message.** Hover over one of your messages and click the pencil to change it in place. Press Return to send: that message and everything after it are replaced by your edit and a new reply. Cancel or Escape leaves the chat as it was.
- **Regenerate a reply.** Click the retry icon under any reply for a fresh answer to the same question. Regenerating an earlier reply also drops the messages after it. The old reply stays until the new one starts, so a failed try changes nothing. File Mode edits and sent iMessages aren't undone.
- **Drag and drop files and images.** Drop files or folders on the chat window, the compact panel or the message field to attach them, just like **Attach** (⇧⌘A), or copy them in Finder and paste. A single image, an image dragged from Safari or Chrome, or a pasted image is read like a screenshot.
- **Long chats keep going.** When a chat gets too long for the model, Enigma summarizes the earlier messages instead of dropping them, usually in the background right after a reply. A quiet **Earlier messages summarized** line marks where, and **/compact** does it whenever you like. A long chat moved to a smaller model is summarized too.
- **See how full the chat is.** A small ring in the message field shows how much of the model's room the chat is using: green, yellow from 70%, red from 90%. Hover over it or click it to see what's left.
- **A weather card.** Weather answers start with a card showing the place, the temperature and the sky, for now, one day or several. While it's on screen, the character dresses for the weather: sunglasses, an umbrella, a woolly hat and scarf, or a nightcap.
- **Chat titles that say what it's about.** After the first reply, the chat's own model gives it a short title, like "Weekend trip to Lisbon", in Recents. Only the start of the chat is used, with the same model and provider. Temporary chats aren't titled.
- **Update available.** When an update is ready, the menu bar icon gets a small dot and the chat window shows a quiet **Update available**. Click it to install.
- **A disk image to download.** Each release now also comes as a DMG: open it and drag Enigma to Applications.

## Improved

- **More room in every chat.** Cloud models now get far more of a long chat or document in each request. Local models run with 8K, 16K or 32K of context, chosen from your Mac's memory; change it with **Context size** under **Settings → On this Mac → Advanced**. When a model looks things up, earlier search results shrink to make room rather than the reply failing.
- **Picking a model switches mode.** Choosing a local model in the mode and model menu switches to Local, and a cloud model to Cloud, from Auto too. You can pick one while a reply is running; it takes over once the reply finishes.
- **Selected text stays part of the chat.** Removing a selection no longer makes the model forget what the chat was about. In the window, the selection shows as its own bubble above the message that sent it.
- **A reminder to check important info.** A short line under the message field reminds you that AI can make mistakes, with a stronger one for local models.

## Fixed

- Escape hides the chat even after you've clicked a reply's text.
- Messages with several lines reach the model as lines, so replies no longer show stray `\n`.
- Asking about your texts without Full Disk Access now shows the card to turn it on, instead of a reply saying Enigma has no access.
