# Enigma 0.13.2

Report a bug from inside Enigma, coloured code blocks, a calmer dark mode, and asking about selected text in more apps.

## New

- **Report a bug.** Choose **Report a Bug…** in Help, **Settings → About** or the menu-bar menu, or click the ladybug in the chat window's top-right corner. Describe what happened and send it straight from Enigma. Reports are anonymous unless you add your email for a reply. Logs and the current conversation are only included if you turn them on, and you can preview everything before it's sent. If sending fails, **Email Instead** opens the same report in your mail app.
- **Coloured code blocks.** Code in replies is now highlighted for Swift, Python, JavaScript and TypeScript, shell, JSON, HTML and XML, CSS and SQL. Terminal blocks get a terminal icon, with commands, flags and paths coloured and output dimmed.

## Improved

- **A calmer dark mode.** The bright lime accent is gone: text is a soft sage grey and the accent a deep moss green, so nothing glows against the dark background. Light mode is unchanged.
- **Ask about selected text in more apps.** Enigma reads your selection once and, when an app doesn't share it, copies it for you and puts your clipboard back afterwards. It's quicker, and now works in apps like ChatGPT that didn't before.

## Fixed

- Location no longer asks again and again, and Enigma now appears in the Location Services list. **Settings → Permissions** and the tour have a **Turn on…** for Location too.
- System Settings is no longer hidden behind Enigma's windows while you change a permission.
- The summon shortcut brings a covered chat window to the front instead of hiding it.
