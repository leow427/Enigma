# Enigma 0.11.0

Bigger local models that stay fast, commands that understand plain wording, and downloads that survive a dropped connection.

- **Recommendations fit your Mac's real speed.** Enigma measures your Mac's memory bandwidth with a quick GPU test and recommends the smartest model that still replies quickly. On a 24 GB M5 Pro that is now Gemma 4 12B instead of Qwen3.5 4B.
- **Commands from plain wording.** Turn on **Settings → General → Commands → Recognize commands from your wording** and Enigma turns on the matching command as you type, shown as a chip in the composer. "Has Dad replied yet" or "text Sam that I'm here" uses Messages; "take your time" or "double-check your answer" turns on thinking; "make this more formal" with selected text becomes an **/edit**; "translate this" translates. It runs on fixed rules on this Mac, with no extra model call, and is off until you turn it on.
- **Bigger models on smaller Macs.** The larger families now come in 3-bit and IQ4_XS sizes too. On a 24 GB Mac, Qwen3.8 27B fits at 3 bits and is offered as **smarter, slower replies**. A model that is fast at some size uses its highest-precision fast size; one that is fast at none offers its smallest IQ4_XS-or-better size that still reaches 8 tokens per second, and drops to 3 bits only when none does. A 3-bit model counts as 15% less capable when the choices are ranked, so it wins only when it is clearly stronger, and when it is recommended, its own 4-bit size can be offered as **smarter, slower replies**. Speed estimates for the new IQ sizes may be optimistic until you run **Check performance**.
- **A refreshed catalogue.** New: Qwen3.5 2B, Qwen3.6 35B-A3B, Qwen3.8 27B and Gemma 4 31B, plus more sizes of Qwen3.5 9B, Gemma 4 12B and Gemma 4 26B-A4B, for Macs from 8 GB to 128 GB. Gemma 4 E4B and Ministral 3 8B and 14B stay, mostly as choices under **All models**; copies installed with 0.10.1 show **Update** once, which downloads the same files again to move them to the new llama.cpp. SmolVLM2 and MiniCPM-o leave the catalogue; installed copies keep working under **On this Mac**.
- **Three clear choices.** Every picker shows the same **recommended**, **faster** and **smarter, slower replies** options.
- **Downloads survive a dropped connection.** A brief Wi-Fi drop no longer restarts a model download: each part resumes from the bytes already on disk. While a model downloads and installs, Enigma keeps the Mac from idle-sleeping; the display can still sleep.
- **Keep chatting while a model downloads.** Cloud chat and your current local model work during a download; Enigma waits for the reply in progress before switching to the new model.
- **Selected text in VS Code.** Double-tap Option now picks up text selected in VS Code and editors built on it (VS Code Insiders, VSCodium, Cursor, Windsurf). Enigma uses their copy only when VS Code confirms a real selection, so a whole line you didn't select is never attached, and your clipboard is put back afterwards.
- **One Local models page.** Settings → Discover and Hugging Face file downloads are gone. Settings → Local models shows the choices for this Mac, your installed models and every catalogue model.
- **Check this Mac** replaces **Detect Mac capabilities** and **Refresh recommendations**, and measures the bandwidth again.
- **A newer llama.cpp (b11734)** reads full-screen screenshots on Gemma 4 correctly. Installed models show **Update** once, which downloads the package again; until then the installed copy keeps working.
- **/screen no longer stalls on the first capture.** When macOS is slow to start reading text, Enigma stops waiting after three seconds and lets the model read the image instead.
- **Smoother long replies.** Streaming replies parse their Markdown as they arrive instead of starting over with each new piece, so long answers stay responsive.
- **Models no longer in the catalogue get no update.** They, including Gemma 4 12B QAT, stay on their old llama.cpp runtime, which misreads screenshots on Gemma models. If you use Gemma 4 12B QAT for screenshots, install the new Gemma 4 12B from Settings → Local models.
