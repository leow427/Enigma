# Enigma 0.10.0

Enigma now keeps itself up to date.

- **Updates arrive by themselves.** Once a day Enigma checks for a new version, downloads it, and installs it the next time it quits. This is the last version you need to download by hand.
- **Restart when it suits you.** When an update is ready, the menu-bar menu shows **Restart to Update**. Choose it to install now, or keep working and it installs when Enigma quits.
- **You stay in control.** Settings → General → Updates has two switches: one for the daily check and one for downloading and installing automatically. **Check Now** looks for an update straight away.
- **It settles into Applications.** If you open Enigma from Downloads or anywhere else, it offers to move itself into Applications and reopen, because it can only update itself from there.
- **Shortcuts that stay out of the way.** ⌥⌃ now opens Enigma only when you press and release those two keys on their own, so other apps' ⌃⌥ shortcuts no longer open it. Show or hide chat history with **⌃⌘S**, open the selection panel's chat in the window with **⌘O**, and attach files with **⇧⌘A**. The Option-S shortcut for Settings is gone, so Option-S types its character again; use **⌘,** or the menu-bar menu.
- **Your permissions stay.** Updates keep Enigma's identity, so Screen Recording, Accessibility and your saved keys carry over.

Only Enigma's version number is sent when it checks for updates.
