# Enigma 0.13.0

A new welcome and a hands-on tour, a Settings window that's easy to find your way around, and shortcuts you can change.

## New

- **A hands-on tour.** Enigma shows you around the real app: ask about the web, places and weather, write code, ask about text you select in another app, tidy a file, and text someone from Messages, with every reply an example and nothing sent. The tour's card sits beside the chat, never over it. Already using Enigma? Choose **Take the tour** in a new chat, or replay it any time from **Settings → General**.
- **Choose your own shortcuts.** **Settings → Shortcuts** lets you change any shortcut: opening Enigma, asking about selected text, every window shortcut, and any slash command. Shortcuts that work in any app can be keys, modifiers pressed together, or a double tap. **Same as summon** lets one shortcut both open Enigma and ask about what you've selected.
- **Find any setting.** Settings now has a page for each part of Enigma, grouped in the sidebar, with a search field that finds a setting by name or by what it does.

## Improved

- **A friendlier welcome.** Setup is shorter and livelier, and the character follows you from step to step.
- **Every permission in one place.** **Settings → Permissions** lists Accessibility, Screen Recording, Full Disk Access, Contacts, Automation and Location, each with a button to the right place in System Settings.
- **Shorter, clearer settings.** Rows have one short line; the longer explanation is behind ⓘ, and rarely needed options are under **› Advanced** on each page. Groups of settings sit together on cards.
- **Help shows your shortcuts.** The Help sheet lists the shortcuts you've chosen.
- **Advanced settings… goes straight there.** In the mode and model menu, it opens Cloud with its advanced options showing.
